# RecurringLabel

Marks an order that was generated from a recurring order (a cafe's standing order), with a repeat mark in `delft`.

**Props:** optional children — "Recurring" by default; on the customer's My recurring orders list use the days instead ("Tue, Thu, Sat").

- Delft blue is used for nothing else but this label and focus, so it never reads as a status.
- When a recurring order has a generation note (an item was dropped), the whole admin row gets a `wheat-soft` background and the note in `wheat-ink` — the label itself does not change.
